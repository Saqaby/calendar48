# التقويم الهجري ١٤٤٨هـ — مخطِّط المهام

موقع صفحة واحدة يعرض تقويم سنة ١٤٤٨هـ (يونيو ٢٠٢٦ – يونيو ٢٠٢٧) كاملًا، ويتيح إضافة المهام وإدارتها. يعمل دون إنترنت بعد فتحه، ولا يحتاج خادمًا ولا قاعدة بيانات.

**عرض مباشر:** بعد النشر سيكون الرابط بهذا الشكل — `https://<اسم-حسابك>.github.io/taqweem-1448/`

---

## ما الذي يقدّمه

**التقويم**
- بيانات ١٤٤٨هـ كاملة: أطوال الأشهر ومطابقاتها الميلادية.
- الطبقات الرسمية: نهايات الأسبوع، الإجازات المدرسية، رواتب الموظفين، إجازات الأعياد، اليوم الوطني ويوم التأسيس ويوم العلم، شهر رمضان، والفصول الأربعة. كل طبقة يمكن إظهارها أو إخفاؤها.
- أربعة عروض: الشهر، الأسبوع، القائمة، والسنة كاملة في جدول واحد.

**المهام**
- ثلاثة أنواع: يوم واحد، ممتدة بين تاريخين، ومتكررة.
- تكرار يومي وأسبوعي (بعدة أيام) وشهري هجري، مع أنماط: يوم محدد، آخر يوم في الشهر، أو ترتيب أسبوعي مثل «ثاني ثلاثاء».
- خيارا تخطّي نهايات الأسبوع وتخطّي الإجازات.
- تعديل أو حذف تكرار واحد دون بقية السلسلة.
- سحب الشريط لنقل المهمة، وسحب طرفه لتمديد مدتها.

**أدوات**
- حاسبة أيام العمل بين تاريخين.
- خريطة ازدحام أسبوعية.
- نظرة سريعة على نسبة الإنجاز وتوزيع التصنيفات.
- تصدير ملف `.ics` لتقويم الجوال أو Google Calendar.
- طباعة: الشهر على A4 عموديًا، والجدول السنوي على A3 عرضيًا.
- وضع ليلي، واختصارات لوحة مفاتيح: `N` مهمة جديدة، `T` اليوم، `/` بحث، و`M W L Y` للتنقل بين العروض.

## النشر على GitHub Pages

### الطريقة الأولى: من المتصفح دون أي أوامر

1. سجّل الدخول في <https://github.com> ثم اضغط **New repository**.
2. اجعل الاسم `taqweem-1448`، واختر **Public**، ثم **Create repository**.
3. في الصفحة التالية اضغط **uploading an existing file**، واسحب الملفين `index.html` و`README.md`، ثم **Commit changes**.
4. ادخل **Settings** ← **Pages** من القائمة الجانبية.
5. في **Source** اختر **Deploy from a branch**، وفي **Branch** اختر `main` والمجلد `/ (root)`، ثم **Save**.
6. انتظر دقيقة أو دقيقتين وحدّث الصفحة، وسيظهر رابط الموقع في أعلى الصفحة نفسها.

### الطريقة الثانية: عبر Git من جهازك

```bash
git init
git add index.html README.md
git commit -m "التقويم الهجري ١٤٤٨هـ"
git branch -M main
git remote add origin https://github.com/<اسم-حسابك>/taqweem-1448.git
git push -u origin main
```

ثم فعّل Pages من **Settings ← Pages** كما في الخطوتين ٥ و٦ أعلاه.

### تحديث الموقع لاحقًا

ارفع نسخة جديدة من `index.html` فوق القديمة (أو `git push`)، وسيتحدّث الموقع خلال دقيقة. إن لم يظهر التغيير، حدّث الصفحة تحديثًا قسريًا: `Ctrl + Shift + R` أو `Cmd + Shift + R`.

## أين تُحفظ المهام

تُحفظ داخل متصفح الجهاز نفسه (`localStorage`)، ولا تُرسل إلى أي خادم. وهذا يعني:

- المهام لا تنتقل تلقائيًا بين الأجهزة أو المتصفحات.
- مسح بيانات المتصفح يمسحها.

لنقلها بين جهازين: افتح زر **⇅** في الأعلى، انسخ النص، ثم الصقه في الجهاز الآخر واضغط **استيراد**.
