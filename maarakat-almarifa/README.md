# معركة المعرفة

لعبة مسابقات معرفية جماعية تُدار من جهاز مقدّم واحد وتُعرض على شاشة كبيرة. واجهة عربية بالكامل (RTL)، تعمل دون خادم أو حسابات، والحفظ محلي في المتصفح.

لا يوجد بنك أسئلة داخل اللعبة: يطرح المقدّم الأسئلة من كتابه، وتعرض الشاشة مستوى السؤال المطلوب (٥ جنود = سهل، ١٠ = متوسط، ٢٠ = صعب) ورقمه المتسلسل في المباراة.

## التشغيل

```bash
npm install
npm run dev          # تطوير: http://localhost:5173
npm test             # اختبارات منطق اللعبة (٢٩ اختبارًا)
npm run build        # نسخة إنتاج في dist/ (تُرفع على أي استضافة ثابتة)
npm run build:single # ملف HTML واحد مستقل في dist-single/index.html يعمل بفتحه مباشرة
```

## البنية

| المسار | الدور |
|---|---|
| `src/engine/engine.ts` | منطق اللعبة كدوال نقية: الاحتساب، الأدوار، الجولة الأخيرة، الفاصل، التراجع، الحفظ |
| `src/engine/types.ts` | الأنواع والثوابت (٥/١٠/٢٠، ٥ و١٠ ثوانٍ، ١٠ جنود للعودة) |
| `src/engine/engine.test.ts` | اختبارات الأرصدة والفوز والتعادل والتراجع وترقيم الأسئلة والاستعادة |
| `src/ui/*` | الشاشات: الافتتاحية، الإعداد، المعركة، السؤال، التتويج، القواعد |

حالات اللعبة: `choose_action` ← `choose_stake` ← `question` (مراحل: `reading` ← `buzz` ← `answering` ← `decided`) ← تأكيد ← الدور التالي، ثم `tiebreak` عند التعادل، ثم `finished`.

## افتراضات اتُّخذت

- عدد الجنود عند البداية من مضاعفات ٥، حتى لا يبقى جيش برصيد بين ١ و٤ لا يسمح بأي مهمة.
- في المواجهة: مهلة طلب الإجابة = مدة الإجابة العامة (٣٠ ث افتراضيًا). إذا انتهت دون طلب يُحتسب «إخفاق الجيشين».
- المواجهة: من يجيب صحيحًا يأخذ جنود المواجهة من الآخر (بحد رصيد الخاسر). إذا أخفق الجيشان يخسر المبادر جنود المواجهة ولا يكسبها أحد.
- الأسئلة الفاصلة من المستوى المتوسط، لا تغيّر الأرصدة، وأول جيش متعادل يجيب صحيحًا يفوز.
- «إنهاء المباراة» اليدوي يُعلن الفائز وفق الأرصدة الحالية (مع فاصل عند التعادل)، ويمكن التراجع عنه.
- عدم تكرار الأسئلة مسؤولية المقدّم؛ رقم السؤال المتسلسل يساعده على تتبّع موضعه في الكتاب.
- المؤثرات الصوتية مولّدة بالمتصفح (Web Audio) دون ملفات خارجية.

## قيود معروفة

- الحفظ محلي في المتصفح نفسه؛ لا مزامنة بين أجهزة، ووضع التصفح الخاص قد يمنع الحفظ (تظهر رسالة تنبيه).
- التحكيم يدوي بالكامل من المقدّم، ولا يوجد تصحيح آلي للإجابات.
- ساعة المباراة (في وضع الوقت) تتوقف عند إغلاق الصفحة وتُستأنف يدويًا بعد الاستعادة.
